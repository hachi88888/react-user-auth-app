## 📖 概要

ReactとTypeScriptを用いて作成したユーザー管理アプリです。
外部API（JSONPlaceholder）と通信し、ユーザー一覧の取得および詳細表示を実装しています。また、Contextを用いたログイン状態管理と認証ガードを実装しています。

本アプリはUdemy講座を基に作成し、認証管理や責務分離への理解を深めるために、機能追加および構造改善を行いました。
